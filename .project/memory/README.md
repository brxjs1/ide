# Memória

Fatos aprendidos durante sessões, que não são convenção nem decisão. Um por linha,
com data. O agente propõe; você aprova.

Formato:

```text
- 2026-10-02 — <fato curto e verificável> (fonte: <arquivo, commit ou conversa>)
```

Quando um fato virar regra, mova para `conventions/`. Quando virar escolha
arquitetural, vire ADR em `decisions/`.
