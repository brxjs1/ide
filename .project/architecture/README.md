# Arquitetura

Visão alvo e módulos: ver `docs/ROADMAP.md`.

Quando um módulo ganhar código, crie aqui um arquivo por módulo (`core.md`, `agent.md`,
`ui.md`, ...) com:

- responsabilidade em uma frase
- entry points (arquivo:função)
- dependências de entrada e saída
- fluxo principal (diagrama em texto)
- armadilhas conhecidas
